================================================================================
                         FLUJO DE EJECUCIÓN TÍPICO
================================================================================

1. El programa muestra el MENÚ
2. Eliges un test (1-6)
3. El test INICIALIZA los datos de prueba
4. El test EJECUTA la función
5. El test MUESTRA el resultado
6. Presionas ENTER para volver al menú
7. Puedes repetir con otros tests

OPCIÓN 7 = Ejecuta TODOS los tests en secuencia

================================================================================
                         INDICADORES DE ÉXITO
================================================================================

✓ = Test pasó correctamente
✗ = Error encontrado
! = Advertencia (puede o no ser un error)

Si ves ✓ al final, significa que el funcionamiento es correcto.

================================================================================
                         CÓMO INTERPRETAR ERRORES
================================================================================

ERROR: "Segmentation fault"
  └─ Problema con punteros o memoria no asignada
     Revisar: malloc(), punteros inicializados, índices válidos

ERROR: "expected ';' before"
  └─ Sintaxis inválida en C
     Revisar: Paréntesis, llaves, puntos y comas

ERROR: Los items no se incrementan/decrementan
  └─ Lógica incorrecta en la función
     Revisar: num_items++, num_items--

ERROR: La comparación de puzles no funciona
  └─ Problema con strcmp()
     Revisar: Espacios en blanco, mayúsculas/minúsculas
